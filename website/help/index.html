30 秒搞懂

即刻对话不是又一个桌面 AI。豆包、WorkBuddy、Cursor、ChatGPT 你继续用；缺的是更好的语音输入。它对着你正在用的输入框说话、把字贴进去，从不自动发送。

你想做什么 用哪个 怎么按 贴出去的是什么
懒得打字：微信、邮件、Cursor 里敲注释 即刻对话 点按开始，说完再点一下 你说的原话（可去「嗯啊」、改错别字）
对着 AI 说需求，但口语太散 与AI对话 按住同一颗键，说完松手 整理过的任务说明（屏幕上的报错、代码会写进去）
聊天窗回不过来 帮我对话 快速双击 按人设起草的回复，仍要你自己发
屏幕上有字、题、英文，想问一眼 看屏幕 另一套组合键（默认 Command / Win + Shift + 1） 答案出在浮窗和剪贴板，不往别人家输入框里贴提示词
Mac 语音键默认右 Command（设置里可改成右 Option / Fn） Windows 语音键是 Alt（不能改） 随时按 Esc 立刻停下

同一颗语音键：点按是贴原话，按住是加成提示词。帮我对话、看屏幕是另外的手势。App 指挥台顺序是即刻对话 → 与AI对话 → 帮我对话 → 看屏幕；官网场景把与AI对话放前面，只是宣传顺序不同。

新手从这里开始

按这个顺序走一遍。先完成一次点按贴字，再学按住。

  1. 确认系统

    Windows 可在首页下载安装包。macOS 目前是内测，官网不提供 dmg，请不要找「选择 macOS 安装包」。官方会员或自配 Key 需要能上网；本地模型可离线，要另配。

  2. 安装并打开

    Windows 运行安装器，打开后看到指挥台四条能力。托盘里也会留着，关掉窗口不等于退出。

  3. 选模型跑法

    三选一，到 App「模型」页完成。不想填 Key：登录官方会员（可用体验积分先试语音）。已有豆包 / OpenAI 等 Key：填自己的地址和 Key，不扣本产品积分。要离线：配本地语音和对话模型。

  4. 授权权限

    Mac 需要麦克风（说话）、屏幕录制（按住加成 / 帮我对话 / 看屏幕；点按贴原话不截屏）、辅助功能（全局快捷键和往别的 App 填字）。首次打开有分步引导。勾完若键没反应：完全退出再打开，不要只关窗口。Windows 先给麦克风；快捷键被占用就去设置改键。

  5. 第一次成功（30 秒）

    打开记事本或微信输入框 → 点一下右 Command（Windows 点 Alt）→ 说「你好，这是我的第一句」→ 再点一下。字贴进去、没有发出去，就算成功。下次要对着 Cursor 或豆包说需求，再改用按住。

四个能力怎么用

每项都是：一句话、什么时候用、怎么按、别和谁搞混。

即刻对话：点按贴原话

懒得打字时用。贴的是你说的话，不是提示词。

什么时候用

微信、邮件、写稿，以及 Cursor / IDE 里说一句注释或短指令。只要嫌敲字慢。

  1. 光标放进输入框
  2. 点一下触发键，开始录音
  3. 说完再点一下结束
  4. 原话贴进去，你自己决定发不发

还要知道

默认会去掉嗯啊呃，并按上下文改转写错字，设置里可关。只去水词不调模型；改错别字会走文本模型。点按不截屏、不扩写。首页「开始说话」也是点按开关，不是按住。

与AI对话：按住，把口语变成能执行的提示词

对着 Cursor、豆包、WorkBuddy、ChatGPT 的输入框按住说话。松手后它看一眼当前屏幕，把随口说的话整理成「做网站 / 做 PPT / 修 Bug / 写方案」那种 AI 能直接动手的任务说明，再贴进去。你看过再回车。

怎么按

  1. 光标放进那个 AI 输入框，屏幕上留着相关内容（代码、报错、对话都可以）
  2. 按住触发键超过约 0.4 秒，底部出现增强提示
  3. 说话，说完松手
  4. 改写后的提示词贴进去，看过再回车

还要知道

空桌面效果差，先把报错或稿子留在屏幕上。已经在点按录音中，再按只会结束贴原话，不会中途变成加成。首页第二行也可以点按开始、再点结束。做 PPT 时，它整理的是「按页生成」的任务说明，不是直接下一个 PowerPoint 文件。

帮我对话：双击起草回复

打开微信 / 飞书 / 钉钉 / 邮件窗口，快速双击语音修饰键。它看当前聊天画面，按联系人人设起草回复并贴进输入框。人设和「去 AI 味儿」在设置里。

输出是回复草稿，不是给 AI 的提示词，也不是浮窗答案。不会自动发送。

看屏幕：整屏问答（答题也在这里）

默认 Mac 右 Command+Shift+1、Windows Win+Shift+1。截整屏，再用语音说明要干什么；说完再按一次同一快捷键结束。答案在浮窗、剪贴板，并写入 App「对话」列表。

题目在屏幕上时可以说「请帮我看这道题选什么」。这不是第五个技能。帮我对话裁的是聊天窗、目的是回消息；看屏幕是整屏、目的是回答问题——不会往微信输入框里贴提示词。

手势别搞混

  • Mac 备用键右 Command+8、Windows 的 Win+8 只有点按贴原话，按住不会加成。
  • 已经在点按录音中，再按只结束并贴原话，不会改成加成。
  • 看屏幕正在听你说话时，点按仍是结束提问，不会开加成。
  • 按住时又按了别的键（例如复制），这次加成会取消。
  • 随时按 Esc 立刻停下。帮我对话是快速双击，看屏幕是另一套组合键。

案例模拟

每个案例：打开什么、按哪个手势、可以怎么说、贴出来大概怎样、常见翻车。按住加成不会逐字复述模型原文，下面是「整理方向」。

即刻对话

微信懒得打字

打开微信输入框，点按语音键。

你可以怎么说

晚上七点老地方，我晚点到十分钟。

贴出来大概会怎样

几乎就是这句原话（「嗯」「那个」会被去掉）。不会自动发送。

翻车：光标不在输入框；录音没结束就切走窗口。

口述回邮件

打开邮件正文，点按。

你可以怎么说

谢谢你发的材料，下周一下午三点可以开会，我先看附件再补充问题。

贴出来大概会怎样

一整段可发的正文。称谓和署名仍建议你自己改一眼。

翻车：在主题栏录音，字贴错地方。

边想边说写初稿

备忘录或文档，点按。

你可以怎么说

方案分三块：先讲现状，再讲我们怎么做会员，最后给两周排期。

贴出来大概会怎样

一篇能改的初稿，不是给 AI 的指令。要整理成任务说明，改用按住。

翻车：说太碎又不停顿，去水词也救不了结构，说完自己分段即可。

对着 Cursor 说，别敲（贴原话）

光标在 Cursor / IDE 输入框，点按。这是 vibe coding 的原话路径。

你可以怎么说

在这个函数里加空值检查，别改别的文件。

贴出来大概会怎样

就是这句指令。需求很散、屏幕上还有报错时，改用按住，让它加成提示词。

翻车：以为点按会「看屏幕改提示词」——那是按住。

与AI对话

对着 Cursor 做网站

屏幕上留着现有页面或编辑器，按住说话。

你可以怎么说

就按现在这个风格，加一个产品介绍和联系表单，手机也要能看。

贴出来大概会怎样

写成「请做一个…网站」的任务，按首页 / 产品 / 联系等模块列清楚，而不是「嗯做一个网站吧」。

翻车：桌面是空的，它看不到你说的「现在这个风格」。

做 PPT / 课件

对着 AI 输入框按住，口述大纲。

你可以怎么说

帮我做个十分钟的分享，就讲我们这个功能怎么用，别写成网站。

贴出来大概会怎样

按页列出标题和要点的任务说明。它要的是按页生成（常见是 HTML 幻灯），不是直接下一个 .pptx 文件。

翻车：期望立刻得到 PowerPoint 附件；看贴进去的说明再回车。

修 Bug

屏幕上留着红色报错，按住。

你可以怎么说

就是这个错，登录以后白屏，我刚才改过路由。

贴出来大概会怎样

把报错、你改过什么、期望结果写成 AI 能动手的调试说明。

翻车：报错已经滚出屏幕；说得太短，加成也补不出上下文。

对着豆包 / ChatGPT / WorkBuddy 写方案

光标在那个 AI 的输入框，按住。

你可以怎么说

客户是餐饮店，想做会员，我还没想清楚积分怎么算。

贴出来大概会怎样

带目标、约束、输出格式的完整 brief，而不是一堆散念头。

翻车：按住不到 0.4 秒，结果只贴了原话。

帮我对话

工作消息秒回

微信 / 飞书 / 钉钉聊天窗在最前，快速双击。

对方大概在说

进度怎样了，今天下班前能给一版吗？

贴出来大概会怎样

一封按人设起草的回复，你改数字和时间再发。

翻车：窗口被挡住；误以为已经发出去了。

群里不好接的话

QQ 群或同学群窗口在前，双击。

对方大概在说

你怎么还不回？是不是不想来？

贴出来大概会怎样

一份拿捏分寸的草稿。人设不对就去设置里改性格包。

翻车：双击太慢被识别成两次点按录音。

邮件回复不犯愁

邮件窗口在前，双击。

你在干嘛

不用说话。它读当前邮件画面，起草回信贴进输入框。

贴出来大概会怎样

一封可改的回信。发出去之前看一眼称呼和附件承诺。

翻车：前台其实是浏览器别的标签，裁到的不是这封邮件。

看屏幕

看屏幕答题

题目留在屏幕上，按看屏幕快捷键，再说完再按一次结束。

你可以怎么说

请帮我看这道题选什么。

你会看到什么

浮窗里给出选项和理由，同时进剪贴板。不是第五个技能。

翻车：按了语音点按，答案不会出现在浮窗。

即时翻译

英文页面在屏幕上，看屏幕快捷键。

你可以怎么说

把这一页翻译成中文，保留小标题。

你会看到什么

浮窗译文。鼠标放在答案上可多看一会儿。

翻车：页面被自己的窗口挡住，截到的不是那段英文。

论文解读

论文段落留在屏幕上，看屏幕。

你可以怎么说

这段到底在说什么，用大白话讲，并标出前提假设。

你会看到什么

解释出现在浮窗，并可在 App「对话」里回看。

翻车：字太小且整屏缩略后难认，放大再问一次。

作业检查

作业照片或扫描件铺满屏幕，看屏幕。

你可以怎么说

看看哪几题做错了，只指出错的，别直接写完整解答给孩子抄。

你会看到什么

按题号指出问题。仍建议你自己核对一遍。

翻车：照片反光、题目被裁掉。

设置、模型、会员

快捷键在设置第一项。价格和积分以「订阅」页为准，帮助里不抄价，避免过期。

数据与不代发

联系人、人设、看屏幕截图写在你电脑上，不会把这些文件上传到即刻对话服务器。Mac：~/Library/Application Support/typenow/ 。Windows：%APPDATA%\typenow\ （一般是 C:\Users\你的用户名\AppData\Roaming\typenow\）。设置「配置与数据」里显示的是当前实际路径，以界面为准。

点按、按住加成、帮我对话都只把文字贴进当前输入框，从不自动发送。进行中任务按 Esc 立刻取消。

本地模型：推理不出机。自配 Key：内容发往你自己的服务商。官方会员：走薄代理再转发上游，会出网——不要理解成「任何服务器都不碰」。

常见问题

如何下载安装？

打开官网首页下载区，下载 Windows 安装包（本站直链）。macOS 正在内测，官网暂不提供 dmg。

Mac 需要哪些权限？

麦克风（语音）、屏幕录制（按住加成 / 帮我对话 / 看屏幕）、辅助功能（全局快捷键与填字）。授权后若快捷键无效，请完全退出再打开 App。

点按和按住有什么区别？

点按贴你说的原话；按住超过约 0.4 秒会看一眼整屏，把口述整理成给 AI 的任务说明再贴入。两种都不会自动发送。详见本页「四个能力」。

会不会自动发送？

不会。贴进输入框之后，回车或发送都由你按。

和豆包、Cursor 是什么关系？

它们仍是你的 AI。即刻对话站在前面：点按帮你输入原话，按住帮你把口语加成提示词。

答题是不是单独一个功能？

不是。触发「看屏幕」，题目在屏幕上时口述「请帮我看这道题选什么」即可。

备用键为什么不能按住加成？

右 Command+8 / Win+8 只做点按贴原话，避免和系统或其他软件抢组合键。要加成请按住主语音键。

Fn 没反应怎么办？

部分外接键盘发不出 Fn。换回右 Command 或右 Option，并确认辅助功能已勾。

数据存在哪？

本机 typenow 目录，见上方「数据与不代发」。设置页可打开文件夹。

官方会员和自配 Key 有什么区别？

官方会员免填第三方 Key，按次扣统一积分；自配 Key / 本地模型不消耗本产品积分，费用按你的服务商账单。

如何开通或更换套餐？

打开「订阅」页或 App 个人中心，登录后用 Stripe 支付；也可联系客服线下办理。档位与个人中心一致，价格以订阅页为准。

积分不够怎么办？

可购买加量包，或升级更高档位；也可临时改用自配 Key / 本地模型继续使用。

找不到更新日志？

页脚有「更新日志」入口；也可在 App 内帮助页查看。

如何改快捷键？

App 设置 → 快捷键表，点「修改」后按下新键。与AI对话不能单独改，始终按住即刻对话那一颗键。
