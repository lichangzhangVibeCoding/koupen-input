# 品牌与功能命名设计（口喷输入）

> 状态：**已落地**  
> 原则：先文档后代码；通用软件定位；对外名 + 一句话解释同时出现在界面，降低「不知道怎么用」的成本。

---

## 1. 产品定位（通用）

**口喷输入**是本机运行的对话助手：把聊天窗口里的对话按人建档，记住人设与历史，用快捷键把「你说的话」或「该回的话」填进输入框（不自动发送）。

- 不面向某一行业（不再使用主播 / 公会 / 榜一大哥 / 刷礼物等话术）  
- 目标用户：需要维护多段私聊、又希望少打字的人  
- 数据仅存本机；用户主动触发；粘贴后由用户自行确认发送  

---

## 2. 对外名与一句话（必须成对出现）

| 层级 | 对外名 | 一句话解释（界面副文案） |
|---|---|---|
| 产品 | **口喷输入** | 本机对话助手：记人设、攒记忆，帮你少打字 |
| 能力 A | **我来口喷** | 你说，我转成字并贴进当前输入框 |
| 能力 B | **帮你口喷** | 看当前聊天截图，按人设生成回复并填入（不发送） |

约定：

1. 凡出现对外名，附近必须有一句话解释（标题下方、卡片副标题、或首次引导）。  
2. 一句话用白话，写「做什么 / 结果是什么」，不写技术词（Whisper、Vision、OCR）。  
3. 危险动作仍单独提示：不自动发送、需本机权限等。

## 3. 界面落点（规划）

### 3.1 全局

| 位置 | 文案 |
|---|---|
| 窗口标题 / 菜单栏 App 名 | 口喷输入 |
| 侧栏品牌主标题 | 口喷输入 |
| 侧栏品牌副文案（一句话） | 本机对话助手：记人设、攒记忆，帮你少打字 |
| 安装包 / DMG 名 | 口喷输入（如 `口喷输入-0.1.0-arm64.dmg`） |
| `package.json` productName | 口喷输入 |

### 3.2 首页（第一屏就讲清两件事）

结构建议：

1. 品牌：**口喷输入** + 产品一句话  
2. 两张能力卡（或两行），每张：**对外名 + 一句话 + 怎么触发**  
   - **我来口喷** — 你说，我转成字并贴进当前输入框  
     触发：点按空格键左侧 **Command** 开始，再按一次结束  
   - **帮你口喷** — 看当前聊天截图，按人设生成回复并填入（不发送）  
     触发：默认 **快速双击左 Command**（以设置里为准）  
3. 次要入口：模型、联系人、设置  

首页不要堆权限长文；权限放设置页即可，首页一句「需麦克风 / 屏幕录制 / 辅助功能」可链到设置。

### 3.3 侧栏导航用词

| 原 | 新 |
|---|---|
| 首页 | 首页 |
| 客户 | **联系人** |
| 模型 | 模型 |
| 设置 | 设置 |

### 3.4 模型页

顶部说明改为产品语境，例如：

> 先把两件事跑通：**我来口喷**（语音）和 **帮你口喷**（截图理解 + 回复）。  
> 下面三槽仍是：语音识别 / 截图理解 / 回复生成——各自对应能力，可「测一下」。

三槽标签可保持技术清晰，但卡片旁可加归属：

| 槽位 | 归属对外名 |
|---|---|
| 语音识别 | 我来口喷 |
| 截图理解 | 帮你口喷 |
| 回复生成 | 帮你口喷 |

### 3.5 设置页

- 原「智能回复快捷键」→ **帮你口喷 · 快捷键** + 一句话  
- 原「启用语音输入」→ **我来口喷** + 一句话 + 开关  
- 「配置与数据」区块保留；说明里「客户」改「联系人」

### 3.6 联系人（原客户）

- 列表 / 详情标题：联系人  
- 「人设」保留；说明改为：我对这个人说话时的语气与边界  
- 去掉大哥、榜一等词  

### 3.7 HUD（底部状态）

尽量带上能力名，用户才知道是哪条链路：

| 状态 | 建议文案 |
|---|---|
| 录音中 | 我来口喷：正在听… |
| 转写中 | 我来口喷：正在转成字… |
| 识别截图 | 帮你口喷：正在看聊天… |
| 生成回复 | 帮你口喷：正在写回复… |
| 已粘贴 | 已填入输入框，请你确认后发送 |
| 失败 | 失败原因（简短） |
