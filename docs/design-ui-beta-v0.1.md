# 口喷输入 · 内测版 UI 优化规划（v0.1）

> 状态：**搁置**（用户暂不推进；对近期 UI 改动不满意，待重新想清楚再议）  
> 目标：内测发布前，把界面打磨到「能给人试用、不穿帮、不迷路」。  
> 原则：不大改架构；紫色系 VI 已定，本版做**信息层级、上手路径、内测可信度**。  
> 前序文档：`design-ui-polish-v1.md`（紫系/首页/模型壳已大部分落地）→ 本文是**内测冲刺增量**。  
> **不据此改代码，直到你明确说开干。**

---

## 1. 内测版要解决什么

内测用户打开 App 后，应在 3 分钟内完成：

1. 知道软件叫什么、两件事干什么（我来口喷 / 帮你口喷）  
2. 配好模型（或一点硅基推荐）  
3. 知道快捷键，并成功试用一次  

当前功能已基本具备，但**仍像「开发中控制台」**：引导弱、版本感弱、部分页信息过密/文案过技术、空态与失败反馈不够稳。

---

## 2. 现状快照（已有 / 缺口）

| 已有（可保留） | 内测缺口（本版要补） |
|---|---|
| 紫系配色与按钮 | 首次启动引导（Onboarding）仍无 |
| 首页 3 步 + 两大能力卡 | 步骤与真实进度未联动（模型是否就绪） |
| 模型页快捷推荐 + 三槽可编辑 | 模型页仍偏长；内测文案可再白话 |
| 联系人搜索 + 纵向详情（人设/画像/微信聊） | 空态引导弱；缺少「内测」标识 |
| 设置：双击 Command / 导出配置 | 热键说明可更一眼懂；权限项可做成清单 |
| HUD 深色胶囊 | 文案长度与失败可读性再收一刀 |
| 品牌名「口喷输入」 | 侧栏/关于缺版本号与内测角标 |

---

## 3. 设计方向（内测专用）

1. **可信**：侧栏底部显示 `内测 v0.1.0`；首页可有轻量「内测」角标（不挡主内容）。  
2. **可懂**：凡出现能力名，必带一句话；快捷键写「单击 / 双击左 Command」，少写内部代号。  
3. **可走完**：首次启动 3 步引导（可跳过）；首页步骤条与模型就绪状态联动。  
4. **可收敛**：模型页默认折叠「高级字段」，先露出推荐 + 三槽摘要，展开再改 URL/Key。  
5. **可失败**：空态、权限不足、模型未就绪，都有明确下一步按钮。  

配色仍用现有紫系（`#8b5cf6` / 深紫底），本版**不重做主题**。

### 4.2 首次启动引导（新增，可跳过）

> **已作废。** 现网新手引导见 [`design-onboarding.md`](design-onboarding.md)：登录后训练场，按默认快捷键练完四个能力。下文三步弹窗不要再实现。

全屏或居中卡片 3 步：

| 步 | 标题 | 内容 | 主按钮 |
|---|---|---|---|
| 1 | 欢迎使用口喷输入 | 产品一句话 + 两大能力名与解释 | 下一步 |
| 2 | 先配模型 | 说明去模型页：硅基推荐或本地套件 | 去配置模型 |
| 3 | 记住快捷键 | 单击左 Command = 我来口喷；双击 = 帮你口喷；并提示三项 Mac 权限 | 开始使用 |

- 完成后写 `settings.onboardingDone = true`（配置文件字段）  
- 「以后再说」直接跳过并记完成  

### 4.3 首页

- [ ] 3 步上手与状态联动：  
  - 步骤 1 完成条件：三槽就绪数 ≥ 1（或 3/3，待确认）  
  - 步骤 2：文案链到设置权限区（无法自动检测权限则仅引导）  
  - 步骤 3：曾成功触发过一次可不做，仅文案提示  
- [ ] 能力卡：未就绪时主按钮旁提示「先去模型页」  
- [ ] 双击/单击文案与设置页完全一致  
- [ ] 底部权限提示一行收干净，链到设置  

### 4.4 模型页（内测最关键）

目标：**新用户只看上半屏就能跑通**。

```
① 状态条：x/3 已就绪 + 进度段
② 快捷上手（硅基 / 本地）——默认展开
③ 三个模型配置——默认「摘要条」；点展开才出本地/在线表单
④ 底部：保存全部 / 去首页试用
```

- [ ] 每个槽摘要行：名称 · 当前模型 · 就绪徽章 · [展开] [测一下]  
- [ ] 硅基推荐区继续列出三模型名（已与你当前常用一致）  
- [ ] 弱化/去掉无操作的「服务商四宫格」（若仍在，改为折叠「服务商状态」）  
- [ ] 失败文案用人话（如「Key 无效」「模型名在硅基不存在」）  

### 4.5 联系人

## 6. 验收标准（内测可发）

1. 冷启动：未做过引导的用户会看到 Onboarding（可跳过）  
2. 首页一眼能分清单击 / 双击  
3. 模型页：只点「硅基推荐」+ Key，三槽摘要变就绪，无需先懂 Base URL  
4. 联系人空态有下一步，不是空白一句  
5. 侧栏或设置可见 **内测 + 版本号**  
6. 全站无主播/榜一等旧话术；对外名均带一句话
