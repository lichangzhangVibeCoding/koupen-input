# UI 专业版优化（v1 内测发布）

> 状态：**紫系主体已落地；内测增量见 `design-ui-beta-v0.1.md`**  
> 目标：内测发布前的界面专业度升级，提升首屏信任感、模型页完成率、联系人管理效率。不大改架构，不改动效框架。

---

## 1. 当前问题

1. **首页布局散**：品牌名、两张能力卡、模型入口、权限说明全部纵向堆叠，重点不突出。  
2. **颜色偏暗且橘色扎眼**：背景暗、品牌橘 `#ff6b4a` 饱和高，像小工具，缺少「内测版」专业感。  
3. **模型页信息密**：服务商 4 张 + 推荐区 + 3 槽位，缺少视觉层级，用户不知道先点谁。  
4. **设置页排列单一**：按钮、权限、导出全部像表单，没有分区徽章。  
5. **联系人页空**：没有搜索、没有标签过滤，空态单薄。  
6. **缺少「首次使用」引导**：新用户直接看到模型页，不知道先做什么。  
7. **底部 HUD 可以更像系统 Toast**：现在太宽、白底、红色 dot 与整体风格冲突。

---

## 2. 设计方向

- **配色**：深紫灰底 + 紫品牌色；专业、科技感，紫色作为主色贯穿品牌/按钮/状态/高亮。  
- **字体**：标题更克制，字距更宽松；正文用更灰的层级。  
- **卡片**：统一 16px 圆角、细微内阴影、分层背景。  
- **状态**：用标签/徽章（Ready / Not ready / 安装中）代替句段。  
- **引导**：首页增加「3 步上手」模块；模型页顶部增加完成进度条。  
- **HUD**：无边框、深色胶囊、小图标，更像 macOS 原生 Toast。  

---

## 3. 具体改动（页面级）

### 3.1 全局 / 侧栏

- 配色切换：深紫主背景 `#0d0b14`，面板 `#151220`，高亮 `#8b5cf6`（紫罗兰）  
- 侧栏：品牌 + tagline 更紧凑；当前导航项右侧加一个竖条高亮（已有，调为紫色 `#8b5cf6`）  
- 内容区：最大宽度 960px，居中，减少过长行带来的阅读压力  

### 3.2 首页

结构：

```
[品牌区]
  口喷输入
  本机对话助手：记人设、攒记忆，帮你少打字

[3 步上手 - 横向步骤条]
  1 配置模型 → 2 设置权限 → 3 按快捷键试用

[两大能力卡 - 左右并列]
  我来口喷    |   帮你口喷
  一句话      |   一句话
  触发说明    |   触发说明
  按钮        |   按钮

[底部辅助]
  模型 · 设置 · 联系人（图标/文字 tab 式链接）
  macOS 权限提示（弱化，链接到设置）
```

- 去掉「手动触发一次」按钮旁拥挤的 4 个按钮；改为每个能力卡自带一个主按钮。  
- 能力卡右上角可放小状态点（未就绪 / 已就绪）。  

### 3.3 模型页

结构：

```
[标题] 模型
[副标题] 把「我来口喷」和「帮你口喷」跑通，才能用快捷键
[进度条] 3 槽中 2 已就绪（绿色填充）

[推荐区 - 两列卡片]
  硅基流动（在线）      本地套件（本机）
  标签：推荐最快上手     标签：无需 Key
  输入 Key + 按钮       按钮

[能力槽位 - 3 行]
  语音识别 | 状态 | 归属 | 模型 | 测一下
  截图理解 | 状态 | 归属 | 模型 | 测一下
  回复生成 | 状态 | 归属 | 模型 | 测一下
```

- 状态用徽章：就绪 / 未就绪 / 检测中 / 安装中。  
- 服务商卡片改为收起，只在展开时显示，或放到「推荐区」下方小字说明。  
  - 进度条为 3 段，未完成用紫灰，完成变紫罗兰 `#8b5cf6`，整体风格一致。  

### 3.4 设置页

结构：

```
[快捷键]
  帮你口喷 · 快捷键  + 输入框

[我来口喷]
  开关 + 一句话 + 触发说明

[回复上下文]
  条数滑块（10 - 200）

[配置与数据]
  导出配置（不含 Key） / 还原默认

[权限]
  麦克风 / 屏幕录制 / 辅助功能（每个一行，带说明）
```

- 每个区块用 `section-header` 分隔。  
- 导出不含 Key 用默认主按钮；带 Key 用次级按钮，避免误操作。  

### 3.5 联系人 / 联系人详情

列表页：

- 顶部加搜索框（按名字/标签过滤）  
- 右侧加「手动添加」按钮  
- 联系人卡片显示：头像首字 + 名字 + 渠道标签 + 人设标签 + 最近时间  
- 空态：加插图占位符 / 图标 + 明确文案 + 引导按钮  

详情页：

- 人设区与聊天区分开更清楚：人设区放卡片内，聊天区独立背景  
- 标签输入用胶囊展示，删除 X 在右侧  
- 时间筛选用紧凑的日期输入 + 按钮，不用大占位  
- 消息气泡：更贴近微信的灰/白对比，头像首字母或默认图标  

### 3.6 HUD

  - 改为深色胶囊：背景 `rgba(21,18,32,0.92)`，文字白，边框 `rgba(139,92,246,0.25)`，圆角 24px。  
  - 宽度自适应，最大 360px，最多两行，居中底部。  
  - 左侧小图标：  
    - 录音中：脉冲紫圈  
    - 识别/生成：转圈紫点  
    - 完成：紫色对勾  
    - 失败：红色叹号  
- 关闭时淡隐而不是直接消失。  

### 3.7 首次启动引导（新文件）

做一个 `OnboardingOverlay`（首页或独立）：

1. 欢迎使用口喷输入（品牌 + 一句话）  
2. 模型页入口：二选一配置  
3. 权限说明：三项 Mac 权限，每项可点「去系统设置」  
4. 完成：提示按快捷键试用  

允许「以后再说」跳过。数据存在 `settings.json` 的 `onboardingDone: true`。
