# 看屏幕问答（Screen Ask）

> 状态：**已落地（v0.3.4 含对话归档）**  
> 与「帮我对话」并列：全屏截图 + 语音提问 → 视觉模型回答，并写入 **对话列表**（类似 ChatGPT）。

## 用户流程

1. 按快捷键（默认 Mac **右** `Command+Shift+1` / Win `Win+Shift+1`；Mac 只认右侧 Command）  
2. 截取**整个主屏幕**  
3. HUD + **语音播报**（优先硅基 CosyVoice2，失败回退系统 TTS）：「我看到屏幕了，你想让我做什么？」→ 播完再开麦听  
4b. 回答完成后 HUD 展示，并简短语音播报回答（可截断）  
4. 用户口述，例如：「看左边文档，帮我总结写了什么」  
5. 再按一次同一快捷键（或单击右 Command / Alt）结束录音  
6. 转写 → 视觉模型结合截图回答 → HUD 展示 + 剪贴板  
7. **同时归档**：截图、问题、回答写入当前「对话」；侧栏 **对话** 可回看

## 对话归档（ChatGPT 式）

| 项 | 说明 |
|---|---|
| 入口 | 侧栏「对话」→ `/chats` |
| 列表 | 会话标题（首问摘要）+ 最近一条预览 |
| 详情 | 气泡线程：用户问题、当时截图缩略图、助手回答 |
| 新对话 | 「新对话」后，下次快捷键写入新会话 |
| 继续 | 打开某个会话即设为「进行中」；右侧可**打字续问**或点「语音续问」/快捷键，均追加到该会话 |
| 多轮 | 回答时带上本会话近期文字上下文；当前轮仍附最新整屏图 |
| 密度 | 左侧会话列表偏紧凑（窄轨、小字号）；主区占满高度，底部固定输入条 |
| 删除 | 删会话及磁盘截图，不可恢复 |

### HUD 长答案

答案浮窗可滚轮上下查看；答案态临时接收鼠标（其它进度态仍穿透点击）。

自动消失（避免正看着就被关掉）：

1. **按时长**：按答案字数估算阅读时间（约 4 字/秒），最短约 20 秒、最长约 90 秒；短答仍约 20 秒。  
2. **悬停暂停**：鼠标在答案卡片上时冻结倒计时（方便滚轮细看）；移出后按剩余时间继续，且至少再留约 12 秒。  
3. 答案仍写入剪贴板，并归档到「看屏幕」对话列表；HUD 收起后可回 App 续看。

### 整屏视觉输入（读字精度）

整屏问答/答题送模型前只缩长边、转 JPEG（不裁 ROI）：

- 长边约 **1600px**、JPEG 质量约 **88**（比聊天窗 ROI 更清晰；密集列表/校名易混时靠清晰度 + 提示词）
- 提示词要求：**名称与旁边数字成对读取**；问「最多/最少」时先核对几条再下结论，禁止把 A 的人数安到 B 名下

## 与帮我对话的区别

| | 帮我对话 | 看屏幕 |
|---|---|---|
| 截图范围 | 前台聊天窗（裁 ROI） | 整屏 |
| 目的 | 生成可粘贴的聊天回复 | 回答关于屏幕的问题 |
| 建档 | 联系人 + 消息 | **对话列表**（截图+问答） |
| 输出 | 粘贴进输入框 | HUD + 剪贴板 + 归档 |

## 看屏幕答题（Screen Quiz）

与「看屏幕」共用对话归档，但流程更短，且**拆成两步模型**：

1. 按快捷键（默认 Mac **右** `Command+Shift+2` / Win `Win+Shift+2`）  
2. 截整屏 → **不问你要干什么、不开麦**  
3. **视觉模型（截图理解）**：只读题——题号、题干、选项，原文转写，不答题（建议 ≥32B VL，如 `Qwen/Qwen3-VL-32B-Instruct`；8B 易读错整屏考题）  
4. **文字模型（回复生成）**：对照内置知识库，只输出正确答案（题号+答案；无解析、无客套；DeepSeek-V3 等即可）  
5. HUD + 剪贴板；可短播答案  

| | 看屏幕 | 看屏幕答题 |
|---|---|---|
| 用户口述 | 要 | 不要 |
| 模型 | 视觉模型直接答 | 视觉读题 → 文字模型作答 |
| 输出 | 按你的要求回答/办事 | **只给正确答案** |
| 默认快捷键（Mac） | 右 Command+Shift+1 | 右 Command+Shift+2 |

设置：`screenQuizEnabled`（默认开）、`screenQuizHotkey`。
