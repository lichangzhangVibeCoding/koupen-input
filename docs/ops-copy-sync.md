## 产品一句话

不是又一个桌面智能体，是站在豆包 / WorkBuddy / Cursor / ChatGPT **前面的语音搭子**。对着正在用的输入框说话，把字贴进去，**从不自动发送**。

勿再当主定位：**本机对话助手**、**蓄水池**、**场景包**（技术记录可以，用户界面不要当卖点）。

## 四个能力

**客户端指挥台顺序不变：** 即刻对话 → 与AI对话 → 帮我对话 → 看屏幕。  
官网场景组可以把「与AI对话」放前面，那是宣传顺序，不等于 App。

| 能力 | 手势 | 贴出 / 结果 | 文案要点 |
|---|---|---|---|
| **即刻对话** | **点按** 开始，说完再点 | 原话（可去水词 / 改错别字） | 微信、邮件、写稿 + **Cursor / IDE 贴原话**（vibe coding 不是按住） |
| **与AI对话** | **按住** 同一颗语音键约 0.4 秒 | 口语变成能执行的提示词 | 点名 WorkBuddy / 豆包 / Cursor / ChatGPT；做网站 / PPT / 修 Bug / 写方案 |
| **帮我对话** | **快速双击** | 按人设起草的回复 | 仍要用户自己发送 |
| **看屏幕** | 默认 Command / Win + Shift + 1 | 浮窗 + 剪贴板 + 对话列表 | 答题并入（说「这道题选什么」）；不是第五技能 |

能力 A / B 共用语音键，不另开快捷键。首页第二行（与AI对话）可点按开始、再点结束。

## 平台差（只核对，不改默认键）

| | Mac | Windows |
|---|---|---|
| 语音键 | 默认右 Command（设置可改右 Option / Fn） | Alt（不能改） |
| 帮我对话 | 快速双击右 Command | 快速双击 Alt |
| 看屏幕 | 右 Command+Shift+1 | Win+Shift+1 |
| 权限 | 麦克风、屏幕录制、辅助功能 | 麦克风、屏幕捕获 |
| 备用键 | 右 Command+8 仅点按贴原话 | Win+8 仅点按贴原话 |

备用键、0.4 秒、Command+8 **只写帮助**，首页指挥台不写。Esc 随时停。
