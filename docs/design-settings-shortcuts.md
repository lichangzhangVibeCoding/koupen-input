# 设置页改版：快捷键表 + 分组

> 状态：**已落地**  
> 相关：`docs/design-voice-trigger.md`（即刻对话触发键三选一）· `docs/design-prompt-enhance.md`（点按原话 / 按住增强）  
> 「与AI对话」是快捷键表第二行：展示「按住」同一语音键，不可单独改绑定；不另加开关。

## 目标

参考常见桌面端「快捷键独立成区 + 芯片展示」体验，把散落在多张卡片里的热键收拢；设置其余项按能力分组，避免和首页指挥台心智打架。

不做成 IDE 式百条命令浏览器——本产品约 3 个全局能力键（与AI对话与即刻对话共用语音键；看屏幕答题并入看屏幕）。

## 信息架构

```
设置
├── 快捷键          即刻对话 / 与AI对话 / 帮我对话 / 看屏幕 + Esc；芯片；修改 / 行内恢复；底部「还原全部快捷键」
├── 能力开关        即刻对话 / 去水词 / 改错别字 / 看屏幕
├── 帮我对话偏好    性格包、去 AI 味儿（不含热键）
├── 语言
├── 高级            上下文条数
├── 配置与数据      本机路径（可打开文件夹）、导出、恢复全部默认（整份 settings）
└── 权限
```

## 快捷键表

| 命令 | 按键绑定 | 操作 |
|---|---|---|
| 即刻对话 | Mac：右 Command / 右 Option / Fn 三选一（默认右 Command）；Win：Alt（只读）。**点按贴口述** | Mac：修改；行内恢复默认 |
| 与AI对话 | **按住**同一语音键 ≥400ms（首页可点按开始 / 再点结束） | 与即刻对话同一键（不可单独改） |
| 帮我对话 | 推荐双击修饰键，或自定义组合 | 修改 · 恢复 |
| 看屏幕 | Mac：`右 Command+Shift+1`；Win：`Win+Shift+1`（内部存 `Super+Shift+1`） | 修改 · 恢复 |
| Esc 取消进行中 | `Esc` | — |

约定：

1. 绑定以 **芯片**（`kbd`）展示，与首页指挥台同源文案（`formatHotkeyLabel` / `formatVoiceTrigger*`）。  
2. **还原全部快捷键**只重置：`voiceTrigger`、`hotkey`、`screenAskHotkey`（仍会写回遗留的 `screenQuizHotkey` 默认值以免旧配置脏数据，但不再注册）；不动人设、语言、模型 Key。  
3. **恢复全部默认**（数据卡）仍重置整份 `settings.json`。  
4. **按下录制**：点「修改」后直接听键；组合键自动写成 Electron 加速键；即刻对话听右侧 Command / Option / Fn。Esc 取消录制。帮我对话可一键切回「推荐双击」。  
5. 保存仍走底部统一「保存」；还原快捷键可立即写入并重注册热键。

## 视觉

沿用墨色信号 VI 与现有 `settings-card`；快捷键表对齐首页 `home-cmd` 的名 / 一句 / `kbd` 节奏，不引入第二套侧栏导航。
