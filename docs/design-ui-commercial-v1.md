# 商用 UI 大改版 v1（0.5.0）

> 状态：**已落地（0.5.0）**  
> VI：[`design-vi-ink-signal.md`](design-vi-ink-signal.md)（色板不变）  
> 气质：Linear / Raycast 向效率工具——图标轨、指挥台首页、疏朗层级、少阴影。  
> 相关：[`design-marketing-site.md`](design-marketing-site.md) · [`design-releases.md`](design-releases.md)

## 相对旧 polish 的作废点

- 不再用宽文字侧栏堆 5 个长链；改为图标轨 + hover 名。  
- 首页不再是「三能力竖卡海报」；改为指挥台操作块（名 / 一句 / 快捷键 / 按钮）。  
- 设置不再是单长表单；改为分组面板。  
- 禁止为「更花」加重多阴影、紫渐变、粒子动效。

## 壳层

- 左侧 **图标轨**（`--rail-w` ≈ 68px）：首页、对话、联系人、模型、更新、设置  
- 轨顶「即」标；当前项电青竖条 + soft 底；切换 ≤150ms  
- 主内容区居中，`--content-max` ≈ 920px；页边距随窗口 `clamp` 缩放  
- 默认窗口约 1180×760，最小约 800×560  
- 轨底显示 `v{version}`

## 首页指挥台

- 品牌名（英雄级）+ 一句话 tagline  
- Esc 取消提示一行  
- 四块操作块：即刻对话 / 与AI对话 / 帮我对话 / 看屏幕（图标 / 名 / 一句话 / 快捷键 `kbd` / 主按钮；与AI对话与即刻对话共用语音键）  
- hover 微抬（无强 glow）

## 其它页

| 页 | 规格 |
|---|---|
| 设置 | 分组：快捷键 / 能力开关 / 帮我对话偏好 / 语言 / 高级 / 数据 / 权限（见 `docs/design-settings-shortcuts.md`） |
| 模型 | **先选跑法**（官方 / 自配 Key / 本地）三选一；三槽只显示能力状态，细调收进「高级」 |
| 对话 | 会话列表行更疏朗 |
| 联系人 | 列表行无重阴影 |
| 更新 | 读打包的 `releases.json`；对比当前版本；链 GitHub / 宣传站 |
| 权限引导 | 墨底遮罩 + 步进卡片；无紫 |

## HUD

保持墨底电青（见 VI）；文案与「进行中 Esc」一致。

## 验收

- 无品牌紫；轨导航六项齐全  
- 首页指挥台一眼可读四能力（与AI对话为第二行）  
- 更新页有发版列表且与宣传站同源
