即刻对话怎么用

同一颗键，两种手势：点按贴原话，按住按屏幕增强成提示词。都不会自动发送。

Mac 默认右 Command（可在设置改成右 Option / Fn） Windows 为 Alt

点按：贴原话

微信、备忘录、浏览器——只要嫌打字慢。

  1. 光标放进输入框
  2. 点一下触发键，开始录音
  3. 说完再点一下结束
  4. 原话贴进去，你自己决定发不发

按住：增强提示词

对着 ChatGPT、Cursor 等 AI 输入框说话，它会扩写成一份能执行的任务说明；屏幕上有报错或代码时会写进去。

  1. 光标放进那个输入框，屏幕上留着相关内容
  2. 按住触发键超过约 0.4 秒，底部出现增强提示
  3. 说话，说完松手
  4. 改写后的提示词贴进去，看过再回车

注意

  • Mac 备用键 右 Command+8、Windows 的 Win+8 只有点按贴原话，按住不会增强。
  • 已经在点按录音中，再按只结束并贴原话，不会改成增强。
  • 看屏幕正在听你说话时，点按仍是结束提问，不会开增强。
  • 按住时又按了别的键（例如复制），这次增强会取消。
  • 随时按 Esc 立刻停下。帮我对话是快速双击，看屏幕是另一套组合键。

常见问题

如何下载安装？

打开官网首页下载区，选择 macOS 或 Windows 安装包。包托管在 GitHub Releases。

Mac 需要哪些权限？

麦克风（语音）、屏幕录制（按住增强 / 帮我对话 / 看屏幕）、辅助功能（全局快捷键与填字）。授权后若快捷键无效，请完全退出再打开 App。

点按和按住有什么区别？

点按贴你说的原话；按住超过约 0.4 秒会看一眼整屏，把口述扩写成给 AI 的任务说明再贴入。两种都不会自动发送。详见本页上方说明书。

官方会员和自配 Key 有什么区别？

官方会员免填第三方 Key，按次扣统一积分；自配 Key / 本地模型不消耗本产品积分，费用按你的服务商账单。

如何开通或更换套餐？

下载 App → 个人中心登录 → 选择档位联系客服线下开通。套餐说明见「订阅」页，与个人中心一致。

积分不够怎么办？

可购买加量包，或升级更高档位；也可临时改用自配 Key / 本地模型继续使用。

找不到更新日志？

页脚有「更新日志」入口；也可在 App 内「更新」页查看。
