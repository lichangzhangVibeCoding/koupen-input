# 说明书：点按贴原话 · 按住增强提示词

> 给用户看的操作说明。工程规格见 [`docs/design-prompt-enhance.md`](design-prompt-enhance.md)。  
> 官网帮助：`https://www.lizhenning.com/other/typenow/help/`（源码在 lizhenning `other/typenow/help/`；品牌域启用后为 www.talknow.cn/help/）。

## 这是什么

「即刻对话」还是原来那颗键，多了一种手势：

| 你怎么按 | 贴进输入框的是什么 | 会不会自动发送 |
|---|---|---|
| **点按**一下，说完再点一下 | 你说的**原话** | 不会 |
| **按住**超过约 0.4 秒，说完松手 | 结合当前屏幕**改写后的提示词** | 不会 |

按住适合对着 ChatGPT、Cursor、邮件草稿等 AI / 长文本输入框说话：按任务类型套场景包（做网站 / PPT / 修 Bug / 写方案），改成能执行的任务说明。屏幕上有报错或代码时会写进去。你看过再回车。

## 触发键

| 平台 | 默认键 | 可改 |
|---|---|---|
| Mac | **右 Command**（空格键右侧） | 设置 → 语音：右 Command / 右 Option / Fn |
| Windows | **Alt** | 固定，不能改 |

硬件备用 `右 Command+8`（Mac）/ `Win+8`（Windows）**只有点按贴原话**，按住不会增强。

## 点按：贴口述

1. 把光标放进任意输入框（微信、备忘录、浏览器都行）。  
2. **点一下**触发键，底部提示正在听。  
3. 说话。  
4. **再点一下**结束。  
5. 口述贴进输入框，并留在剪贴板。默认会去掉嗯啊呃等水词、按上下文改转写错字（设置里可关）。你自己决定发不发。

## 按住：增强提示词

1. 把光标放进你要对 AI 说话的输入框，屏幕上留着相关内容（代码、报错、对话都可以）。  
2. **按住**触发键超过约 0.4 秒，底部出现「松手后会按屏幕增强提示词」。  
3. 对着麦克风说你想让那个 AI 做什么。  
4. **松手**。它会静默截一张整屏、转写你的话、改写成提示词，再贴进去。  
5. 看一眼再回车。**不会自动发送。**

按住过程中如果又按了别的键（例如复制），这次增强会取消，不贴字。随时 **Esc** 立刻停下。

## 不要和这些搞混

- **帮我对话**（快速双击右 Command / Alt）：看聊天窗，按人设起草回复。  
- **看屏幕**：截整屏后回答你的问题，答案出在浮窗，不是改写输入框里的提示词。  
- 已经在点按录音中：再按只结束并贴原话，不会改成增强。  
- 看屏幕正在听你说话：点按仍是结束提问，不会开增强。  
- 首页「开始说话」按钮：只走点按开关。

## 权限

- 麦克风：录音  
- 屏幕录制：按住时静默截整屏（点按贴原话不截屏）  
- Mac 辅助功能：全局快捷键和往前台 App 填字  

授权后若键没反应，请完全退出再打开 App。
