💬 知识域一：Prompt 工程

涉及证书：华为云Prompt工程(#5) · 阿里云内容生产(#9) · 科大讯飞Prompt工程师(#10) · Datawhale AI Prompt Engineer(#15)

4 个证书共享此知识域
  • 大模型基础原理：语言模型演进（SLM→NLM→PLM→LLM）、能力边界与局限性
  • 采样参数：Temperature（随机性控制）、Top-P（核采样）、Top-K、 их ныш解读
  • 核心提示技巧：
    • Zero-shot：不提供示例，直接指令
    • Few-shot：提供 2-5 个示例引导输出格式
    • Chain-of-Thought (CoT)：引导模型逐步推理，"Let's think step by step"
    • 角色设定：赋予模型专业身份（"你是一个资深数据分析师"）
    • 指令设计：明确任务、约束条件、输出格式
  • 结构化 Prompt 框架：
    • APE：Action(行动) + Purpose(目的) + Expectation(期望)
    • CARE：Context(背景) + Action(行动) + Result(结果) + Example(示例)
    • RACE：Role(角色) + Action(行动) + Context(背景) + Expectation(期望)
    • COAST：Context + Objective + Actions + Scenario + Task
    • CRISPE：Capacity + Role + Insight + Statement + Personality + Experiment
    • RISE：Role + Input + Steps + Expectation
    • TRACE：Task + Request + Action + Context + Example
    • ROSES：Role + Objective + Steps + Expected + Super
    • LangGPT：结构化模板，# Role / # Profile / # Rules 等
  • Prompt 最佳实践（参考 OpenAI Cookbook）：清晰具体、拆分复杂任务、提供参考文本、减少臆测
  • 星火/盘古平台实操：Token 计数、效果对比、智能体创建
  • 应用场景：客服问答优化、文案生成、代码辅助、多模态生成
🔧 知识域二：微调 Fine-tuning

涉及证书：科大讯飞微调工程师(#11) · Datawhale Fine-tuning(#14) · Datawhale 大模型开发工程师(#20)

3 个证书共享此知识域
  • 微调原理：在预训练模型基础上，用领域数据调整模型参数
  • 微调方法对比：
    • 全量微调 (Full Fine-tuning)：更新所有参数，效果最好但成本高
    • LoRA：冻结原始权重，训练低秩矩阵，显存占用减少 90%+
    • QLoRA：在 LoRA 基础上量化基座模型到 4bit，进一步节省显存
    • SFT (Supervised Fine-Tuning)：监督微调，用指令-回答对训练
    • DPO (Direct Preference Optimization)：直接偏好优化，替代 RLHF
  • 数据集构建：
    • 指令格式：{"instruction": "...", "input": "...", "output": "..."}
    • 数据质量 > 数据数量；正负样本需均衡
    • 噪音数据处理：清洗、去重、过滤低质量样本
    • 标注规范：一致性检查、交叉标注质量校验
  • 训练超参数：学习率（通常 1e-4 ~ 5e-5）、Batch Size、Epochs（通常 3-5）、Warmup
  • 效果评估：Loss 曲线、困惑度 (PPL)、BLEU/ROUGE、人工评估
  • 过拟合/欠拟合：训练集 Loss 持续下降但验证集 Loss 上升 → 过拟合
  • 文生图微调：Stable Diffusion + LoRA 风格化小模型、Checkpoint 选择
  • 平台实操：讯飞星辰 MaaS 平台（零代码/低代码微调界面）
  • RLHF 对齐：RLHF 三阶段（SFT → RM → PPO），DPO 简化流程

📚 知识域四：RAG 检索增强生成

涉及证书：科大讯飞RAG工程师(#13) · Datawhale 大模型开发工程师(#20)

2 个证书共享此知识域
  • RAG 概念：检索增强生成，先检索相关文档再喂给大模型生成回答，解决幻觉问题
  • RAG vs 纯 LLM：RAG 可引用外部知识、回答可溯源、无需重新训练
  • RAG 全流程：
    • 1. 数据导入与预处理：文档加载 → 清洗 → 分块 (Chunking)
    • 2. 嵌入 (Embedding)：文本 → 向量（如 text-embedding-ada-002）
    • 3. 向量存储与索引：FAISS / Milvus / Pinecone / Chroma
    • 4. 检索 (Retrieval)：相似度搜索（余弦相似度、内积）
    • 5. 信息整合与生成：将检索结果拼入 Prompt → LLM 生成回答
  • RAG 演进：
    • NaiveRAG：基础检索+生成，简单但召回率有限
    • AdvancedRAG：优化检索（重排序、查询扩展、混合检索）
    • ModularRAG：模块化设计，可插拔组件
    • AgenticRAG：结合 Agent 自主决策检索策略
  • 文档切分策略：固定大小切分、按语义切分、滑动窗口、递归切分
  • 评估指标：
    • 检索质量：Recall@K、Precision@K、MRR
    • 生成质量：Faithfulness（忠实度）、Answer Relevance（答案相关性）
    • 端到端：RAGAS 框架（检索+生成联合评估）
  • 常见问题：召回不足、噪音文档干扰、上下文窗口超限、多轮对话状态管理
  • RAGFlow：开源 RAG 引擎，支持本地部署
  • 讯飞知识库：API 接口调用、应用原型开发

📝 核心公式与指标速记

分类评估指标（训练师高级 / 微调 / 大模型开发 必考）

Precision (精准率) = TP / (TP + FP) — 预测为正中真正为正的比例
Recall (召回率) = TP / (TP + FN) — 实际为正中被正确预测的比例
Accuracy (准确率) = (TP + TN) / (TP + TN + FP + FN)
F1 Score = 2 × (Precision × Recall) / (Precision + Recall)
CER (字符错误率) = (S + D + I) / N — S=替换 D=删除 I=插入 N=总数

文本生成评估指标（训练师高级 必考）

BLEU = 加权 n-gram 精准率 × BP（短句惩罚） — 评估机器翻译
ROUGE = n-gram 召回率 — 评估文本摘要
PPL (Perplexity) = exp(-1/N × Σ log p(xi)) — 困惑度越低越好
Distinct-1/2 = 不同 n-gram 数量 / 总 n-gram 数量 — 多样性

采样参数（Prompt 工程 / 大模型开发 必考）

Temperature: 控制随机性。T→0 输出更确定，T→1 输出更多样
Top-P (核采样): 从概率累积 ≥ P 的词中采样。P=0.9 取前 90% 概率的词
Top-K: 只从概率最高的 K 个词中采样

向量检索相似度（RAG 工程师 必考）

余弦相似度 = (A·B) / (|A| × |B|) — 值域 [-1, 1]
内积 = Σ(Ai × Bi) — 未归一化时使用
Recall@K = 前 K 个结果中相关文档数 / 全部相关文档数
MRR = 1/|Q| × Σ 1/rank(i) — 第一个相关结果的排名倒数

LoRA 核心公式（微调工程师 必考）

W = W₀ + ΔW = W₀ + B × A — A∈ℝ^(r×k), B∈ℝ^(d×r), r << min(d,k)
QLoRA = 量化基座模型(4bit) + LoRA 微调 — 显存占用减少 75%+
SFT 损失 = -Σ log P(y|x) — 给定输入 x，最大化目标输出 y 的概率

大数据特征 / 知识层级（训练师初级 必考）

大数据 4V: Volume(规模) + Velocity(速度) + Variety(多样) + Value(价值)
DIKW: Data → Information → Knowledge → Wisdom
AI 三驾马车: 算力 + 算法 + 大数据
