安装、权限、会员与常见问题

如何下载安装？

打开官网首页下载区，选择 macOS 或 Windows 安装包。包托管在 GitHub Releases。

Mac 需要哪些权限？

麦克风（语音）、屏幕录制（帮我对话 / 看屏幕）、辅助功能（全局快捷键与填字）。授权后若快捷键无效，请完全退出再打开 App。

官方会员和自配 Key 有什么区别？

官方会员免填第三方 Key，按次扣统一积分；自配 Key / 本地模型不消耗本产品积分，费用按你的服务商账单。

如何开通或更换套餐？

下载 App → 个人中心登录 → 选择档位联系客服线下开通。套餐说明见「订阅」页，与个人中心一致。

积分不够怎么办？

可购买加量包，或升级更高档位；也可临时改用自配 Key / 本地模型继续使用。

找不到更新日志？

页脚有「更新日志」入口；也可在 App 内「更新」页查看。
