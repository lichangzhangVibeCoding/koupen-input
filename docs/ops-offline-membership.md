# 线下会员开通 SOP（运营）

完整产品设计见 [`design-membership.md`](./design-membership.md)。

## 两套能力（不要混开）

| 类型 | 做什么 | 后台入口 | 效果 |
|------|--------|----------|------|
| **按月会员** | 首开 / 升级 / 续费 / 降级 | 用户 → 选中 →「会员变更」 | 按变更类型改档位、到期；可选发积分 |
| **流量包** | 只加积分，不改档位 | 用户 → 选中 →「流量包充值」 | 仅钱包加积分 |

会员档位（由低到高）：`trial` 体验 &lt; `standard` 标准 &lt; `advanced` 高级 &lt; `flagship` 旗舰。

## 日常：用户已转账，后台变更

1. 用户 App 登录个人中心，转账备注手机号；换档用户点「升级 / 申请换档 / 续费」会弹客服微信（**不再静默登记意向**）。
2. 客服打开  
   `https://www.lizhenning.com/other/typenow/talknowAPi/admin/index.php`
3. **用户**页搜索手机号 → 列表看清：**当前档位 / 到期日 / 积分 / 预约降档**
4. 点 **管理** 打开右侧用户卡：
   - **会员变更**：选动作 → 点选目标档 → 设时长/到期 → 选积分策略 → 填付款备注 → 确认  
   - **流量包充值**：只加积分，不改档位
5. 用户 App 刷新即可看到新档位 / 积分

## 会员变更动作（必选其一）

| 动作 | 何时用 | 档位 | 到期 | 积分默认 |
|------|--------|------|------|----------|
| **首开** | 无有效订阅或仅体验后首次付费 | 立刻写入目标档 | 从今天起算 1/3/12 月或自定义 | 发 1 账期月赠 |
| **升级** | 更低档 → 更高档 | 立刻改目标档 | **保留原到期日** | 发「目标档月赠 − 当前档月赠」差额（≤0 不发） |
| **续费同档** | 同档加长 / 到期后续 | 不变 | **在现有到期上叠加**（已过期则从今天起算） | 发 1 账期月赠 |
| **降级（到期生效）** | 更高档 → 更低档（推荐） | 写 `pending_plan_id`，到期再切 | 到期日切档并开新账期 | 切档日发新档 1 账期；**不扣现有钱包** |
| **降级（立刻）** | 紧急立刻降 | 立刻改目标档 | 保留原到期 | 默认不发新月赠；不扣钱包 |

积分策略可在后台覆盖：`差额 / 1 账期 / 按月数倍发 / 不发`。

其它约定：

- 体验 → 付费按 **升级**；付费 → 体验按 **降级**。
- 钱包余额 **永不因降级清零**。
- 每笔变更写订单（channel：`open` / `upgrade` / `renew` / `downgrade` / `downgrade_now`）+ ledger 备注 `from→to`。

## 待履约意向单

历史 `pending` 意向仍可在「开通与充值」页 **确认预约 / 拒绝 / 删除**。  
新客户端不再自动创建意向；以客服微信沟通 + 后台直接变更为主。

## 按月付费怎么理解

- **首开**：选定档位 + 到期；默认发 1 账期套餐积分。
- **升级**：档位立刻变，剩余订阅天数继承；默认只补差额积分。
- **续费**：档位不变，到期延长；默认再发 1 账期。
- **预约降级**：当前仍享受高档至到期；到期后 `/v1/me` 自动切到 pending 档。
- **流量包**：与订阅无关，用完即止。

## 兑换码 / 试用

「兑换码」页生成 → 发给达人 → 用户在个人中心兑换（只加积分，不改档位）。

## 客服话术（简）

- 自配 Key / 本地模型可以一直免费用。
- 官方模式不用填 Key，按积分扣；套餐每月有基础额度，不够可买流量包。
- 升级：补差价后档位立刻变，到期日一般不动。
- 降级：默认到期再生效，期内积分不清空。
- 当前线下转账开通；微信/支付宝后置。

## 在线支付（后置）

`POST /v1/orders` 对 `wechat`/`alipay` 返回 501。主体就绪后接 webhook，同一订单表履约即可。
