# 即刻对话 · 按住说 = 提示词增强

> 状态：**本期落地**  
> 用户说明书：[`docs/guide-prompt-enhance.md`](guide-prompt-enhance.md) · 官网帮助 lizhenning `other/typenow/help/`  
> 相关：`docs/design-voice-trigger.md` · `docs/design-branding.md` · `docs/design-settings-shortcuts.md`  
> 原则：点按贴口述（可选去水词 / 改错别字，见 `docs/design-voice-trigger.md`）；按住才做提示词增强；不新开技能入口；不改看屏幕 / 帮我对话主流程；**不自动回车**。

## 目标

在现有「即刻对话」触发键上加一条手势，不增加首页/设置里的第五个能力：

| 手势 | 结果 |
|---|---|
| **点按**（按下到抬起 &lt; 400ms） | 开始/结束录音 → 转写 → 可选去水词/改错别字 → **口述**贴进当前输入框（不是提示词增强） |
| **按住**（按下后持续 ≥ 400ms） | 静默整屏截图 + 录音；松手 → 转写 → `enhancePromptForAi` → 贴增强后的提示词（不发送） |

给 AI 输入框（ChatGPT、Cursor、邮件草稿等）用：口述意图 + 当前屏幕，改写成可直接粘贴的提示词。不是看屏幕问答，也不是帮我对话写回复。

## 手势与冲突

阈值：**400ms**（keydown 起算）。与双击窗口 380ms 错开：短按仍走单击/双击；长按才进增强。

**一旦进入按住**（满 400ms 且键仍按下、未变成组合）：

1. 取消**本会**单击与双击（清掉待触发的单击定时器，`lastAloneTapAt = 0`）
2. 本会抬起不再切换「点按录音」
3. 本会不会触发帮我对话双击

其它约定：

| 场景 | 行为 |
|---|---|
| 按住过程中按下其它键（组合） | 取消本次增强（丢录音与截图），不贴字 |
| 已在点按录音中 | **不进入增强**；本次按下无论长短都只结束点按并贴原话 |
| 看屏幕听音中 | **不进入增强**；点按仍结束提问（现网） |
| 看屏幕其它忙段 / 点按转写中 | 不抢；可重亮忙碌 HUD |
| Esc | 立刻停下（停麦、丢截图、不粘贴），与 `docs/design-esc-cancel.md` 一致 |
| 首页「开始说话」 | 仍走点按开关，不走按住增强 |
| 硬件 `右 Command+8` / `Win+8` | **仍为点按原话**，不识别按住 |

Mac 语音触发为右 Option / Fn 时：只对该键做按住增强；右 Command 的双击与组合键不变。

Windows：**Alt 点按 = 原话**，**Alt 按住 ≥400ms = 增强**；双击 Alt 仍为帮我对话。`Win+8` 仍点按原话。

## 按住流水线

进入按住后立刻**并行**：

1. **静默整屏截图**：`captureFullScreen()`（desktopCapturer，无快门、无「正在看屏幕」HUD、不抢焦点）
2. **开麦录音**：底部 HUD 提示松手后会增强（勿写成「再按一次结束」）

截屏失败不中断录音；增强时无图则只凭口述改写。

松手后：

1. 停麦 → 转写（现网 STT，官方会员仍按语音分钟扣）
2. 与点按相同的转写后处理（去水词 / 改错别字，见 `docs/design-voice-trigger.md`）
3. `enhancePromptForAi(settings, image | null, transcript)`  
   - 有图：视觉模型 + `reply_vision`  
   - 无图：文本模型 + `reply`  
4. `pasteIntoFrontApp(text, 'keep-clipboard')`  
5. **不按回车 / 不发送**

无声、转写失败、增强失败：HUD 报错，不粘贴。取消（Esc / 组合键）不贴字。

## 增强提示词（模型）

只输出**可粘贴的提示词正文**（给 Cursor / ChatGPT / WorkBuddy 等执行，不是私聊回复，也不是替它作答）。

**核心竞争力（长期）：** 管道只维护一次；好用程度靠 **场景包** 变多变准，不靠第五个技能、不靠把总 prompt 无限加长。

### 技术路线（管道冻结）

```text
按住 → 截屏+录音 → STT → 转写后处理（去水词/改错别字）
              │
              ├─ 读屏摘要（视觉槽；无关则「无相关上下文」）
              ├─ 场景路由：website | ppt | debug | brief | generic
              ├─ 套对应场景包（输出骨架 + 允许补全 + 禁止项）
              └─ 文字模型写出提示词 → 粘贴（不回车）
```

手势 / STT / 粘贴 **不再为新场景改代码**。新场景 = 新包 + 黄金口试。按 **任务类型** 路由，不按前台 App 名（Cursor / 浏览器标题太脆）。

拿不准走 `generic`（通用扩写），**不得**套建站范例。Debug 与建站同时像时，**debug 优先**。

数据：`src/shared/prompt-scenes/`。官网「与AI对话」四卡与四包 id 对齐：`website` / `ppt` / `debug` / `brief`。

### 首发四包

| id | 官网卡 | 输出骨架 | 允许补全 | 禁止 |
|---|---|---|---|---|
| `website` | 做网站 | 祈使建站 + 页面/模块编号 | 用户点到的功能按模块展开；可补导航、响应式 | 不要写成 HTML 幻灯或纯方案 brief；不要把某次试验口试写成默认模块 |
| `ppt` | 做 PPT | **HTML 分页幻灯**（每页一屏）+ 第 N 页标题与要点 | 合理页数、每页 3～5 点、可翻页 | 禁止 .ppt / .pptx / PowerPoint 文件；不要写成网站 |
| `debug` | 写代码 / 修 Bug | 现象、复现、期望、改动范围 | 把屏幕上的报错/文件写进去 | 不要新开产品/官网需求；不编路径 |
| `brief` | 写方案 / 问 ChatGPT | **目标、约束、输出格式** | 补验收与结构 | 不要写成代码补丁或整站需求 |
| `generic` | （回落） | 祈使任务 + 编号 | 轻度补全 | 不要默认套用建站电商模块 |

### 黄金口试（加包必过）

1. 「做一个公司官网，要有产品介绍和联系我们」→ `website`  
2. 「做十页融资 PPT，市场/产品/团队」→ `ppt`，须有「第 N 页」，且约束为 **HTML 幻灯** 而非 .ppt 文件   
3. 对着红字说「修这个」→ `debug`，含报错原文，不含购物车  
4. 「帮我想周报结构」→ `brief`（目标、约束、输出）  
5. 含糊一句 → `generic`，且不得出现无关的在线购买模块  

### 两步调用（有截图时）

1. **截图理解槽**：只抽事实；无关则「无相关上下文」  
2. **回复槽**：口述 + 摘要 + **当前场景包** → 提示词  

两步之间短暂间隔，降低 429。读屏失败则只凭口述路由。无图：只走第 2 步。

官方会员：有图时扣 `reply_vision` + `reply`；无图只扣 `reply`。

### 演进（场景包越加越强）

- **P0（本期）**：路由 + 四包 + 口试  
- **P1**：屏幕上已有上一轮 AI 回复 → 偏 `followup`（补约束，不重开项目）  
- **P2**：翻译/汇总表等新包；每包两条口试；未过口试不准上官网卡  

仍不做：新快捷键、第五技能、自动发送、按进程名硬编码场景、把总规则写成「如果是 PPT 则…如果是代码则…」长文。

## 明确不做

- 不在首页指挥台 / 设置快捷键表加第五行技能  
- 不增加「增强提示词」开关（语音开着即有按住）  
- 不改看屏幕、看屏幕答题、帮我对话主流程与快捷键  
- 不自动回车  
- 硬件 `Command+8` / `Win+8` 不做按住增强  

## 文案

对外仍叫 **即刻对话**，一句话带上两种手势（见 `design-branding.md` / i18n `brand.voice.blurb`）。

HUD 示例：

| 阶段 | zh |
|---|---|
| 按住录音 | 松手后会按屏幕增强提示词 |
| 转写 | 我记下来了… |
| 读屏（有图） | 先看一眼屏幕… |
| 增强 | 正在写成给 AI 的任务说明… |
| 完成 | 增强后的提示词已经填好啦（不发送） |

## 实现要点

- `modifier-tap.ts`：语音键 hold 定时 400ms；忽略 key repeat；进入 hold 后清单击/双击；组合键取消 hold  
- `voice-input.ts`：`beginVoiceHold` / `endVoiceHold`；点按 `toggleVoiceInput` 原路径不动  
- `llm.ts`：读屏摘要 → `matchPromptScene` → 按包扩写  
- `src/shared/prompt-scenes/`：场景包数据与路由  
- 接线：`src/main/index.ts` 的 `modifierTapHandlers`
